scripts, architecture, and operating constraints. The linked docs carry the
details; this page avoids maintaining a second copy of each procedure.

## Maintenance contract

Update the authoritative doc whenever a command or behavior changes, then update
these links only when their destination changes. Run `make docs-index` and
`make docs-check` after moving or adding documented files. Preserve the difference
between supplied replay text, dry-run expectations, and unknown legacy provenance.
Do not run embeddings, inference, research refreshes, or watchers as a side effect
of documentation maintenance. Record unresolved gaps in [known issues](../known-issues.md).
