# Objective Assertion Engineering: Technical Lexicon

- **Objective Assertion**: A deterministic, programmatically verifiable test statement that evaluates to boolean True or False.
  - *Related*: Grader Check, Deterministic Assertion, Automated Test
- **Structural Assertion**: A check verifying the syntax layout, document hierarchy, or markdown formatting of an artifact.
  - *Related*: Heading Check, Table Validator, Format Verification
- **Schema Assertion**: A programmatic validation checking payload structure, types, and required keys against a formal schema.
  - *Related*: JSON Schema, Pydantic Validator, Type Safety
- **Deterministic Content Assertion**: A verification that specific string literals, entity names, or calculated values match truth.
  - *Related*: Exact Match, Ground Truth Check, Value Equality
- **Negative Bounding Assertion**: A check designed specifically to confirm the absence of unwanted artifacts or behaviors.
  - *Related*: Hallucination Check, Anti-Pattern Guard, Boundary Constraint
- **Reconciling Count Assertion**: A validation confirming that summary numbers match the exact count of listed items in the body.
  - *Related*: Parity Check, Count Consistency, Total Verification
- **Vibe Evaluation**: Non-deterministic, subjective grading based on qualitative human or LLM impressions.
  - *Related*: Qualitative Vibe, Subjective Scoring, Grading Flakiness
- **Binary Grader**: An automated function that maps artifact outputs strictly to 1 (Pass) or 0 (Fail).
  - *Related*: Indicator Function, Discrete Scorer, Strict Verification
- **Negative Boundary Tripwire**: An invariant check that triggers an immediate failure and zeroed composite score upon detecting a prohibited artifact or side-effect.
  - *Related*: Circuit Breaker, Hard Constraint, Hallucination Tripwire
- **Circuit Breaker Multiplier**: The mathematical evaluation property where violating a negative bound zeroes the entire score via boolean multiplication ($S_{\text{pos}} \times \prod_j (1 - T^-_j)$).
  - *Related*: Zero-Tolerance Gating, Multiplicative Nulling, Tripwire Gate

- Dynamic Honeypot Syscall Interception: Synchronous or asynchronous tracing of OS kernel system calls to detect unauthorized file, network, or process access.
- Canary Traps: High-attraction synthetic decoy files (.env, credentials) planted to catch boundary violations.
